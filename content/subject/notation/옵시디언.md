## template

### template 생성

옵시디언의 root 밑에 `template` 폴더를 만든다. 그리고 그 아래에 파일을 2개 만든다. 현재까지는.

![[Pasted image 20251108133501.png]]  

- date.md
- title.md

date.md 파일 title에 오늘 날짜를 넣어주는 템플릿이 들어있고,  
title.md 파일에는 title에 title이 들어가게 해 놓았다.

date.md 파일 내용
```markdown
---
title: {{date:YYYY.MM.DD. ddd}}
draft: false
---
```

title.md 파일 내용
```
---
title: {{title}}
draft: false
---
```
`{{title}}` 등의 변수들은 https://help.obsidian.md/plugins/templates 에서 찾을 수 있다. 


![[Pasted image 20251108133112.png]]  

이제 설정창에서, 바로 위에서 만든 template 폴더를 설정해 준다.   이렇게 해 놓으면 저 폴더 아래에 있는 md 파일들은 모두 템플릿이라 생각하고 화면에 보여준다.

파일을 만들고 ctrl + p 를 하면,  

![[Pasted image 20251108135412.png]]
