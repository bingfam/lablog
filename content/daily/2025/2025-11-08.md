## 옵시디언 화면에 보여지는 폰트 바꾸기

.obsidian\snippets\myfonts.css 파일을 만들고 아래 내용을 넣는다.  
이 파일을 수정, 저장하는 즉시 옵시디언 UI가 바로 바뀐다.
```css
/* 인터페이스 영역 글꼴 바꾸기 */
body {
  font-family: 'Nanum Gothic', 'NanumGothic', '나눔 고딕', '나눔고딕', 'cookierun', sans-serif;
}

/* 뷰(View) 영역, 특히 에디터와 리딩 뷰의 텍스트 폰트를 강제 */
.markdown-source-view.mod-cm6 .cm-editor,
.markdown-source-view.mod-cm6 .cm-scroller,
.markdown-preview-view {
    font-family: '강원교육모두 light', 'Nanum Gothic', 'NanumGothic', '나눔 고딕', '나눔고딕', 'cookierun', sans-serif;
    /*font-size: 1.2em;*/
}
```
에디터 영역 글자크기는 obsidian 환경설정에서 바꿔줄 수 있다.
